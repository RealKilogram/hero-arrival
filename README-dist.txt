英雄登场
========

双击 Start.bat 启动，程序会缩到右下角托盘。
右键托盘图标可以：触发一次 / 设置 / 显示范围 / 窗口置顶 / 鼠标穿透 / 浏览器源 / 退出。

> 本程序不附带任何画面素材，刚装好是空的。
> 先用「设置 → ＋ 导入素材」放一个素材包进去，再给素材设个热键才能触发。

> 重要：请把这个文件夹放在**没有小数点的路径**下（比如 D:\HeroArrival\）。
> 放在 2026.11 这类带点的目录里，Windows 会误判路径并弹「无法验证发布者」。

素材怎么来
----------
程序播放的是「带透明通道的帧序列素材包」，一个素材包就是一个文件夹：

  <素材名>/
    clip.json   { "name": "显示名", "count": 帧数, "fps": 帧率, "width": 宽, "height": 高 }
    frames\     000.webp 起的连续帧（必须有 alpha 通道）
    sounds\     可选，放 mp3/wav/ogg，触发时随机播一个

加素材：右键托盘 →「设置」→「＋ 导入素材」→ 选素材包文件夹。
也可以直接把素材包目录丢进 resources\app\assets\clips\，重启程序会自动识别。

自己从视频做素材
----------------
项目仓库里有工具 tools\clipgen.py（需要自备 Python 环境）：

  pip install numpy opencv-python-headless pillow onnxruntime

还需要两个文件（体积原因没随包分发，到项目仓库查看获取方式）：
  tools\rmbg14.onnx   BRIA RMBG-1.4 抠像模型（约 168MB）
  tools\ffmpeg.exe    ffmpeg

然后：
  python clipgen.py -i 你的视频.mp4 -o 输出目录 --name 角色名 --fps 60

跑完把输出目录拖进「导入素材」。注意通用抠像不保证每个镜头都完美，
背景复杂、强光、半透明特效多的镜头需要自己修。

浏览器源（直播姬 / OBS）
------------------------
右键托盘 →「浏览器源（直播姬 / OBS）」→「复制地址」，把地址粘到直播姬的
「浏览器源」里，宽度高度填 1920x1080 或你直播的分辨率。
之后按热键，转播画面里就会出现，自己屏幕不受影响（除非你开了「本机同时播放」）。

常见问题
--------
Q: 打开后按热键没反应？
A: 还没有素材。托盘右键 → 设置 → 导入素材，然后给素材设热键。

Q: 双击没反应？
A: 看 resources\app\app.log 最后几行；也可能是杀毒软件拦了，加白名单。

Q: 播放位置不对 / 只显示一部分？
A: 素材按「铺满屏幕」等比缩放显示，取景以素材本身为准。

Q: 怎么退出？
A: 右键托盘图标 → 退出。

Q: 程序能开多个吗？
A: 不能，重复启动会被挡回去并提示「程序已经在运行了」。
