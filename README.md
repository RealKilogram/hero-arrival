# 英雄登场 · Hero Arrival

> 按一下热键，一个带透明通道的角色特写从屏幕前冲出来，播完自动消失，不挡鼠标、不抢焦点。

给直播和日常使用的全屏叠加特效小工具。程序本身不带任何画面素材——放什么内容由你自己导入（带透明通道的帧序列素材包，附带的抠像工具能把视频转成素材包）。

> **本仓库不包含任何游戏/影视素材。** 下面提到的「爱弥斯」只是开发时的测试样例，不会随程序分发。

## 功能

- **全局热键**：每个素材独立热键，游戏里也能触发，不用切窗口
- **真透明**：窗口无边框、无背景、鼠标穿透，特效叠在游戏/桌面之上而不是盖一块黑底
- **多素材**：一个素材一个热键，互不干扰；播放期间再按不会叠播
- **随机语音**：每个素材可以配任意多个音效文件，触发时随机播一个
- **直播可用**：内置网页源，直播姬 / OBS 用「浏览器」源直接接入，透明叠加不需要抠像
- **常驻托盘**：单实例运行，右键菜单可触发、改热键、开关置顶与穿透

## 快速开始

### 用打包好的版本

1. 下载 `Hero-win64.zip`，解压到**任意没有小数点的路径**（别放在 `2026.11` 这种目录下，见[常见问题](#常见问题)）
2. 双击 `Start.bat`
3. 右下角出现托盘图标 —— **此时里面是空的**，需要先导入一个素材（见[素材管理](#素材管理)）
4. 导入后按热键（新素材默认没有热键，在设置里点一下热键框按下组合键）

### 从源码运行

需要 Node.js 和 Electron：

```bash
npm i -D electron
npx electron app --no-sandbox
```

`app/` 就是完整的程序目录，`app/config.json` 是配置。

> 仓库里没有附带任何素材，启动后是空的。用下面两种方式之一放一个素材包进 `app/assets/clips/`。

## 画面上怎么出现的

程序为每台显示器建一个**透明、无边框、置顶、鼠标穿透**的窗口，里面只有一个 canvas。热键触发时把预解码好的帧按 60fps 画上去，播完清空。

几处细节：

- **为什么是 webp 帧序列，不是带 alpha 的 webm**：Chromium 把视频层交给 GPU/DirectComposition 合成，在透明窗口里 `drawImage(video)` 会导致画面整块丢失（实测：canvas 里 alpha 数据正常，屏幕上人物却是空的）。逐帧图片走的是普通图像合成路径，稳定。
- **分段预解码**：不会一次性把整段素材全部解码进内存（5 秒素材在 1440p 下约 1.8GB，会撑爆显存）。播放时只保留「前面 1.5 秒 + 刚播过的 0.7 秒」，实测常驻内存约 250MB，长素材也能跑。
- **启动后 2~3 秒**在预解码首帧，这期间按热键**不会丢**，会排队等就绪后补播一次。

## 素材管理

托盘右键 → **设置**（或设置窗口里的素材列表）：

| 操作 | 怎么做 |
| --- | --- |
| 添加素材 | 点「＋ 导入素材」，选一个素材包文件夹 |
| 改热键 | 点素材行里的热键框，直接按下组合键（必须带 Ctrl / Alt / Shift / Win） |
| 重命名 | 点「改名」，输入后回车 |
| 删除 | 点「删除」，4 秒内再点一次确认 |
| 设为当前 | 点素材行本身（托盘「触发一次」和浏览器源默认播这条） |
| 试播 | 点「试播」，不用按热键 |

素材包就是一个文件夹，结构固定：

```
my-clip/
  clip.json      # { "name": "显示名", "count": 120, "fps": 60, "width": 2560, "height": 1400 }
  frames/
    000.webp
    001.webp
    ...
  sounds/        # 可选，放 mp3/wav/ogg/m4a/aac，触发时随机播一个
    a.mp3
    b.mp3
```

- `count` 要和 `frames/` 里的文件数一致，文件名从 `000.webp` 开始连续编号
- `width` / `height` 是原始尺寸，程序按「铺满屏幕并裁掉多余」的方式缩放
- 素材**没有硬性时长上限**，但超过 5 秒时导入会提醒：播放期间这条素材的热键会被占住，播完才能再触发

## 自己做一个素材

素材包就是一个文件夹，三样东西：

```
<素材名>/
  clip.json   { "name": "爱弥斯", "count": 60, "fps": 60, "width": 2560, "height": 1400 }
  frames/     000.webp、001.webp…… 连续帧，必须带透明通道（alpha）
  sounds/     可选，放 mp3 / wav / ogg，触发时随机播一个
```

`clip.json` 里的 `count` 要和实际帧数一致，`fps` 决定播放速度。

把自己的视频转成这种素材包，用配套的抠像工具（**独立仓库**）：

> https://github.com/RealKilogram/hero-clipgen

两种用法：双击 `抠像工具.bat` 开网页界面拖视频进去，或者命令行
`python clipgen.py -i 视频.mp4 -o 输出目录 --name "我的角色" --fps 60`。

抠像用的是通用人像分割模型，**不是每个镜头都能抠得一样好**：画面剧烈缩放、人物和背景颜色接近、大量半透明光效的镜头，模型会漏掉光晕或者带上背景。通用工具省的是体力，复杂镜头仍然要自己看片决定要不要修。

生成好的素材包，用托盘里的「设置 → 导入素材」加进来即可。


## 直播 / 录屏接入

### 浏览器源（推荐）

程序内置了一个本地网页服务：

```
http://127.0.0.1:17321/
```

直播姬：**添加素材 → 浏览器 → 粘贴地址**，宽高按 2560×1400 填，页面自己铺满。

- 背景全透明，**不需要抠像**，直接叠在游戏画面上
- 想让声音从网页源出：地址加 `?sound=1`
- 只想直播里出现、自己屏幕别闪：托盘取消「本机同时播放」
- 网页源依赖主程序在跑，程序退出页面就白了

### 显示器捕获

最省事：抓整个屏幕，特效本来就在屏幕上。游戏用**无边框窗口**模式即可（独占全屏抓不到叠加层）。

### 窗口捕获（不推荐）

直播姬的「窗口捕捉」抓这个窗口是**黑的**。实测原因是 Chromium 的画面走 GPU/DirectComposition 合成，不进 GDI 表面，而这类捕获走 `WM_PRINT`/窗口 DC 接口。OBS 的「窗口采集」（WGC）能拿到，但要自己加色度键。

## 配置说明

`app/config.json`：

```json
{
  "display": "primary",
  "topmost": true,
  "passthrough": true,
  "localOverlay": true,
  "volume": 0.9,
  "clips": [
    { "id": "aemeath", "name": "爱弥斯", "hotkey": "Alt+F", "count": 60, "fps": 60 }
  ],
  "active": "aemeath"
}
```

| 字段 | 说明 |
| --- | --- |
| `display` | `primary` 主屏 / `all` 所有屏幕 |
| `topmost` | 是否永远压在其它窗口之上 |
| `passthrough` | 鼠标是否穿透（关掉才能点特效窗口，但会挡操作） |
| `localOverlay` | 本机是否也播放（关掉只有浏览器源播） |
| `volume` | 音效音量 0~1 |
| `clips` | 素材列表，`id` 对应 `assets/clips/<id>/` |
| `active` | 当前素材 |

> 改完配置要重启程序（或在设置窗口里改，会自动保存）。

## 目录结构

```
app/
  main.js          主进程：窗口、托盘、热键、素材扫描、网页服务
  preload.js       contextBridge 暴露给页面的安全接口
  renderer.js      叠加窗口：分段预解码 + 逐帧绘制 + 音效
  index.html       叠加窗口页面
  settings.html    设置窗口（素材管理）
  livesrc/         浏览器源（直播姬 / OBS 用）
  assets/
    clips/<id>/    素材包：clip.json + frames/ + sounds/
tools/
  clipgen.py       抠像工具：视频 → 素材包
build.ps1          打包脚本（生成 dist/Hero + zip）
```

## 常见问题

**弹「打开文件 - 安全警告：无法验证发布者」？**

把程序（或快捷方式）**放在带小数点的目录里**（比如 `2026.11`）就会这样——Windows 解析路径时把 `.11` 当成扩展名，进而触发附件管理器的检查。换到 `D:\Hero\` 这类路径即可。批处理 `.bat` 也容易被检查，建议直接用 `Start.bat` 里的 exe 命令或做个指向 `electron.exe` 的快捷方式。

**图标不是角色头像？**

同理，快捷方式的图标路径不能落在带小数点的目录里。把 ico 放到 `C:\Users\<你>\AppData\Local\Hero\` 这种干净路径，再指向它。

**按热键没反应？**

- 看托盘图标是否还在（程序被关了 / 崩了）
- 热键被别的软件占用：改用别的组合键（`Ctrl+Alt+Shift+某键` 冲突最少）
- 全屏独占游戏抓不到叠加层：改无边框窗口
- 看日志 `app/app.log`

**播起来像幻灯片？**

素材太大（分辨率 × 帧数）导致解码跟不上。用 `--fps 60 --quality 80` 重新生成，或者接受 30fps。

**内存占用？**

约 250MB（分段预解码的窗口大小），和素材时长基本无关。第一次启动解码首帧时会高一些。
